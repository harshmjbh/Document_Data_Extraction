Page detection – bounding box

Supports image upload, video upload, and live camera. Bounding box is drawn in real time when the browser can read frames. Serve over HTTP (e.g. python -m http.server 8000) for the worker.

1. Image

Upload an image to detect the page.

2. Video

Upload any video. When the browser can read frames, the green box appears in real time.

3. Live camera

Start the camera and point it at a page for real-time detection.
